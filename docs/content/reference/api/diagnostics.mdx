# Diagnostics

## Listeners

<Sig side="both">{"Listeners(): {[string]: number}"}</Sig>

The number of listeners connected to each event, by endpoint name. Use it to spot events with no listener, or listener counts that keep growing because a controller connects without disconnecting.

```lua copy
for name, count in Network.Diagnostics.Listeners() do
    if count > 5 then
        warn(name, "has", count, "listeners")
    end
end
```

For live connect and disconnect notifications, use the [`Listener`](/reference/api/hooks#listener) hook.

## Requests

<Sig side="server">{"Requests(player: Player?): RequestStats?"}</Sig>

Returns server totals, or counters for one player. `Active` counts running handlers, `Peak` is their high-water mark, `Accepted` counts started handlers, `Limited` counts busy replies, `Failed` counts errors raised by handlers, and `Cancelled` counts handlers whose threads the game cancelled. Reading an unknown player returns `nil`. Player departure clears their counters. A handler still running at departure continues to occupy a server slot until it finishes. The replication step reclaims cancelled threads at most once per second.

```lua copy
local stats = Network.Diagnostics.Requests()
print(stats.Active, stats.Peak, stats.Limited)
```
