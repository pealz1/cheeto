# Diagnostics

## Listeners

<Sig side="both">{"Listeners(): {[string]: number}"}</Sig>

The number of listeners connected to each event, by endpoint name. Use it to spot events with no listener, or listener counts that keep growing because a controller connects without disconnecting.

```lua copy
for name, count in Network.Diagnostics.Listeners() do
    if count > 5 then
        warn(name, "has", count, "listeners")
    end
end
```

For live connect and disconnect notifications, use the [`Listener`](/reference/api/hooks#listener) hook.
