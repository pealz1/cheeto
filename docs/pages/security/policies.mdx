# Policies

A policy decides whether a sender may use an endpoint. Endpoints name one with [`Policy`](/reference/fields#policy); you register the rule on the server with [`Security.RegisterPolicy`](/reference/api/security#registerpolicy).

```cheeto copy
function TradeAccept {
    Yield: Coroutine,
    Policy: "trade",
    PolicyGroup: "economy",
    CooldownSeconds: 0.5,
    InvokeTimeoutSeconds: 10,
    Data: u32,
    Return: boolean
}
```

```lua copy
Network.Security.RegisterPolicy("trade", function(context)
    local player = context.Source
    if not Profiles.IsLoaded(player) then
        return false, "profile-not-loaded"
    end
    if Trading.IsLocked(player) then
        return false, "trade-locked"
    end
    return true
end)
```

## How a policy runs

- It runs before the payload is decoded, after auth, cooldown, replay and sender-constraint checks. See [The receive pipeline](/concepts/receive-pipeline).
- It receives a context: `Source`, `Name`, `Channel`, `Policy`, `PolicyGroup`, `Constraints`, `UserId` and `Size`. It does **not** receive the payload.
- Return `true` to allow. Return `false`, optionally with a reason string, to deny. The reason becomes the drop reason in violation reports, and for functions and predicted events it is the reason the client's `Invoke` fails with or its prediction rolls back with.
- A policy that errors denies.

## Unregistered names fail closed

A policy name that nothing registered denies every packet on its endpoints, and the first one logs:

```
[Cheeto]: Policy "trade" is not registered, so every packet on "TradeAccept" is dropped. Register it with Security.RegisterPolicy.
```

There are no built-in policies. A name in the schema is a promise that a rule exists, and the runtime holds you to it: a typo or a forgotten registration shows up as a drop in testing, not as an open endpoint in production.

## Policy groups

A group is a named list of policies that all must pass, in addition to the endpoint's own `Policy`. It lets several endpoints share checks, and lets you [kill](/security/kill-switches) them together.

```lua copy
Network.Security.RegisterPolicyGroup("economy", { "profile-loaded", "not-trade-locked" })
```

A group that is never registered denies, like an unregistered policy. A policy listed in a group that is not itself registered also denies.

## Requiring policies

[`RequirePolicies = true`](/reference/options/security#requirepolicies) drops any client-sent endpoint that declares none of `Policy`, `PolicyGroup` or `Auth`. Turn it on so an endpoint added without any rule fails closed instead of open. `--doctor` and `--strict` report those endpoints at compile time.

## Checking the payload

A policy cannot see the data. To check the data, use the [`Validate`](/security/constraints) hook or check it in your listener. A common split: the policy answers "can this player trade right now?", and the listener answers "does this player own the item in this trade?".
