# Security Toolkit

The repository ships a set of standalone anti-exploit detectors in [`extras/security`](https://github.com/pealz1/cheeto/tree/main/extras/security). They do not depend on a Cheeto schema, so you can drop them into any game.

<Callout type="info">
  If your game already uses a Cheeto schema, start with [Maximum Security](/guides/maximum-security). It covers liveness challenges and server-side movement checks over Cheeto's own transport. Reach for this toolkit when you have not migrated yet, or want a second layer.
</Callout>

## What is included

| Detector | What it catches |
| --- | --- |
| Infinite Yield detection | The Infinite Yield admin script, through four independent GUI fingerprints |
| Movement anti-cheat | Speed, fly, noclip, infinite jump, mass, void teleport, anti-gravity and anti-knockback |

Both detectors share one signed report channel. The server issues a per-session secret, verifies every report against a strictly increasing sequence number, and removes a client that stops sending heartbeats after it has joined.

## Installing

| Script | Location |
| --- | --- |
| `IYDetector.client.luau` | `StarterPlayerScripts` |
| `MovementAnticheat.client.luau` | `StarterPlayerScripts` |
| `IYGuard.server.luau` | `ServerScriptService` |

Every script requires its dependencies from `script.Parent`, so place the shared modules (`Config`, `SecureChannel`, `SecureReport`, `IYSignatures`, `SuspicionScore`, `KnockbackForce`, `MovementConfig`) next to the scripts that use them.

## Tuning the movement detectors

Each detector feeds a per-tick condition into a scoring engine that ramps while the condition holds and decays when it clears.

- The **rollback** threshold is low. Crossing it quietly resets the player's property and position.
- The **report** threshold is much higher. Crossing it reports to the server, which removes the player.

Tune both, per detector, in `MovementConfig.luau`. Keep the gap between them wide: it is what stops lag spikes, server teleports and physics glitches from ever producing a report.

## Limitations

- The Infinite Yield scan can only read containers a LocalScript is allowed to read. UI parented to protected `CoreGui` through `gethui()` is invisible to it; the heartbeat timeout covers the case where the detector is removed.
- The session secret lives in client memory, so signing is defence in depth rather than proof. Keep authority on the server.

The [toolkit README](https://github.com/pealz1/cheeto/blob/main/extras/security/README.md) documents every file, signal and test in detail.
