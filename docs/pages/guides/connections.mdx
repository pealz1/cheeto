# Controller Connections

Cheeto can group generated endpoints and state channels into one connection object that you create during bootstrap and inject into controllers. The connection is a lifecycle and routing layer; every message still uses the generated Cheeto endpoint, so serialization, validation, security policies, and batching are unchanged.

## Define The Typed Traffic

Keep transport data in the schema. For example:

```cheeto copy
struct UIState {
    Visible: boolean,
    Title: string(0..64)
}

event UIAction {
    From: Client,
    Type: Reliable,
    Call: ManySync,
    Data: string(0..32)
}

event UIMessage {
    From: Server,
    Type: Reliable,
    Call: ManySync,
    Data: string(0..128)
}

channel UI {
    Scope: Player,
    TickRate: 20,
    Delta: true,
    Data: UIState
}
```

## Create And Inject A Client Connection

Bind friendly route names to generated endpoints once, then pass the connection through each controller's `Init` method.

```lua copy
local Network = require(ReplicatedStorage.Network.Client)

local connection = Network.Connection.new({
    Routes = {
        Action = Network.UIAction,
        Message = Network.UIMessage,
    },
    State = {
        UI = Network.UI,
    },
})

for _, controller in ControllerList do
    controller:Init(connection)
end
```

The controller owns only its subscriptions and behavior:

```lua copy
function UIController:Init(connection)
    self._connection = connection

    connection:On("Message", function(message)
        self:ShowMessage(message)
    end)

    connection:OnState("UI", function(state)
        self:SetVisible(state.Visible)
        self:SetTitle(state.Title)
    end, true)
end

function UIController:Dismiss()
    self._connection:Send("Action", "Dismiss")
end
```

Passing `true` to `OnState` immediately supplies the current snapshot in addition to future changes. Use `GetState` when a controller only needs a read:

```lua copy
local currentUI = connection:GetState("UI")
```

## Bind A Server Connection To A Player

Set `Target` for a player-scoped server connection. Cheeto automatically passes that player as the first argument when the connection sends or reads state.

```lua copy
local connection = Network.Connection.new({
    Target = player,
    Routes = {
        Message = Network.UIMessage,
    },
    State = {
        UI = Network.UI,
    },
})

connection:Send("Message", "Welcome")
local currentUI = connection:GetState("UI")
```

For server-side incoming events, generated listeners still receive the sending player. A target does not filter incoming listeners; keep authorization in Cheeto policies or check the player inside the handler.

## Push State Through The Connection

`SetState`, `PatchState`, `ClearState`, and `FlushState` write to a bound channel so a controller can push an update without reaching around the connection for the raw endpoint. They follow the same targeting rule as `Send`: with a `Target` the player is supplied for you.

```lua copy
connection:SetState("UI", { Visible = true, Title = "Welcome" })
connection:PatchState("UI", { Title = "Ready" })
connection:FlushState("UI")
```

Without a `Target`, pass the player yourself, exactly as you would to `Send`:

```lua copy
local connection = Network.Connection.new({ State = { UI = Network.UI } })

connection:SetState("UI", player, { Visible = true, Title = "Welcome" })
connection:FlushState("UI") -- no target, so this flushes every subscriber
```

Writes are server-only. Client channels are read-only, so `SetState` on a client connection errors rather than silently doing nothing.

## Lifecycle And Late Binding

Connections track every subscription created by `On`, `Once`, and `OnState`. Tear down the connection when its controller group is no longer needed:

```lua copy
connection:Disconnect()
-- connection:Destroy() is an alias
```

`Disconnect` is idempotent and releases all tracked subscriptions. Sends and new subscriptions fail after teardown so stale controllers cannot silently keep using the network.

Routes and channels can also be added before injection:

```lua copy
local connection = Network.Connection.new()
    :Bind("Action", Network.UIAction)
    :Bind("Message", Network.UIMessage)
    :BindState("UI", Network.UI)
```

Available methods are `Bind`, `BindState`, `SetTarget`, `Send`, `On`, `Once`, `GetState`, `OnState`, `IsConnected`, `Disconnect`, and `Destroy`.
