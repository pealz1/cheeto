# Maximum Security

Use `SecurityPreset = Maximum` for new production integrations. It turns on the v2 hardened defaults in one place: policy enforcement, strict client shield reporting, client liveness challenges, server-observed character integrity, client kicks, randomized remote names, RemoteEvent decoys, protocol handshakes, compact frame parsing, replay rejection, and production capture redaction.

```cheeto copy
option Casing = Pascal
option ClientOutput = "Network/Client.luau"
option ServerOutput = "Network/Server.luau"
option TypesOutput = "Network/Types.luau"

option SecurityPreset = Maximum
option Version = 1
option MinimumSchemaVersion = 1

event DamageRequest {
    From: Client,
    Type: Reliable,
    Call: SingleAsync,
    Policy: "damage",
    Risk: Damage,
    Priority: Critical,
    MaxPacketBytes: 128,
    Data: u16
}
```

Compile the schema:

```sh copy
cheeto path/to/network.cheeto --yes
```

## Server Bootstrap

Put this in a normal Script under `ServerScriptService`.

```lua copy
local ReplicatedStorage = game:GetService("ReplicatedStorage")
local Network = require(ReplicatedStorage.Network.Server)

Network.Security.OnViolation(function(report)
    warn("[Cheeto]", report.Reason, report.Player, report.Action)
end)
```

## Client Bootstrap

Put this in a LocalScript under `StarterPlayerScripts`.

```lua copy
local ReplicatedStorage = game:GetService("ReplicatedStorage")
local Network = require(ReplicatedStorage.Network.Client)
```

The generated client module starts the shield automatically when `SecurityPreset = Maximum` is compiled in. The generated server module creates the real remotes, rotates their names, publishes their current names through the generated remote root, and installs decoy remotes that report and kick when exploit tooling fires them.

## Client Integrity Challenges

Maximum security periodically sends each client a one-time challenge over Cheeto's existing reliable buffer transport. The client coalesces overlapping challenges, runs the built-in runtime invariants plus every registered game sampler, and returns a completion receipt. The server accepts only the current challenge id and nonce, rejects stale or replayed completion counters, and records missing, expired, malformed, or unhealthy receipts as decaying evidence.

Register cheap, deterministic checks for game-specific client systems:

```lua copy
local release = Network.Security.OnIntegritySample(function(context)
    local controllers = require(script.Parent.Controllers)
    return {
        Healthy = controllers:IsStarted()
            and controllers.Inventory:IsBound()
            and controllers.Character:IsBound(),
    }
end)

-- Call release() when the owning system is destroyed or hot-reloaded.
```

The server can inspect or control the challenge lifecycle:

```lua copy
local snapshot = Network.Security.ClientIntegrity(player)
print(snapshot.Score, snapshot.ValidReceipts, snapshot.ConsecutiveMisses)

Network.Security.ChallengeIntegrity(player) -- immediate diagnostic challenge
Network.Security.GrantIntegrityGrace(player, 10, "loading-large-map")
```

A single miss does not kick. Evidence decays, successful receipts reduce the score, and a kick requires both `ClientIntegrityScoreThreshold` and `ClientIntegrityMaxConsecutiveFailures`. The receipt checksum is a framing/completion marker rather than a client secret; treat this as liveness and tamper evidence, not proof that a privileged client is clean.

## Server Character Integrity

Character integrity samples the replicated `HumanoidRootPart` and `Humanoid` on the server. It evaluates elapsed time, horizontal and vertical displacement, bounded assembly velocity, configured movement limits, network ping allowance, `WalkSpeed` mutation, seating, long-frame resynchronization, and collidable traversal. It never accepts a client-reported position as authoritative input.

The action mode is deliberately staged:

- `Observe` retains bounded evidence and telemetry only.
- `Report` also emits `Security.OnViolation` entries.
- `Correct` reports and moves sustained outliers back to the last server-observed safe CFrame.
- `Kick` adds the final kick threshold; `CharacterIntegrityKick = true` is also required.

Maximum security defaults to `Correct`, while automatic character-integrity kicks remain off. Tune in `Observe`, review real sessions, then move through `Report` and `Correct` before enabling `Kick`.

Use the generated teleport wrapper whenever the server intentionally moves a character:

```lua copy
Network.Security.TeleportCharacter(player, destinationCFrame, 2)

-- For launch pads, cutscenes, vehicles, or another movement system:
Network.Security.GrantMovementGrace(player, 3, "launch-pad")
-- After replacing a character or completing a custom move:
Network.Security.ReconcileCharacter(player, false)
```

Diagnostics are available without exposing mutable runtime state:

```lua copy
local playerState = Network.Security.CharacterIntegrity(player)
local allState = Network.Security.CharacterIntegrity()
print(playerState.Score, playerState.LastReason, playerState.LastAction)
```

## What The Shield Detects

The client shield is a best-effort tripwire layer. It reports through Cheeto's internal buffer frame, not a separate public RemoteEvent.

- Hooked metamethod and `getrawmetatable` style environments through stack-environment leakage checks.
- Infinite Yield signatures including `IY_LOADED`, executor helper globals, CoreGui text signatures, cached services, and the TextChatService `;setcreatorid` bait pattern.
- Dex Explorer style service caching through weak-reference probes.
- Remote spy UI signatures and decoy remote usage.
- UniversalSynSaveInstance and safe-mode signals including `saveinstance`, `getscriptbytecode`, hidden-property helpers, write-file helpers, and safemode error text.

## Remote Spy Boundary

No Roblox networking library can hide data from the client that receives it. Maximum security makes captured traffic less useful by rotating remote names, using compact buffer frames, trapping decoy remotes, rejecting replay, requiring server-side policies, and keeping sensitive state out of client-origin payloads.

Use server-issued handles or ids instead of sending privileged Instances, secrets, prices, damage, currency, inventory ownership, or admin authority through client requests.

## Optional Tuning

`SecurityPreset = Maximum` is the recommended profile. These options exist for controlled rollouts:

```cheeto copy
option EnableClientShield = true
option ClientShieldStrict = true
option ClientShieldKick = true
option ClientShieldKickMessage = "Security check failed."
option ClientShieldProbeIntervalSeconds = 1.25
option ClientShieldReportCooldownSeconds = 2
option ClientShieldScoreThreshold = 10
option EnableClientIntegrity = true
option ClientIntegrityChallengeIntervalSeconds = 4
option ClientIntegrityReceiptTimeoutSeconds = 8
option ClientIntegrityJoinGraceSeconds = 20
option ClientIntegrityScoreDecayPerSecond = 0.5
option ClientIntegrityCleanReceiptDecay = 2
option ClientIntegrityMissWeight = 4
option ClientIntegrityInvalidWeight = 6
option ClientIntegrityScoreThreshold = 16
option ClientIntegrityMaxConsecutiveFailures = 4
option EnableCharacterIntegrity = true
option CharacterIntegrityMode = Correct
option CharacterIntegrityKick = false
option CharacterIntegritySampleIntervalSeconds = 0.25
option CharacterIntegrityJoinGraceSeconds = 5
option CharacterIntegrityTeleportGraceSeconds = 2
option CharacterIntegrityMaxStepSeconds = 1.5
option CharacterIntegrityMaxHorizontalSpeed = 64
option CharacterIntegrityMaxVerticalSpeed = 120
option CharacterIntegritySpeedMultiplier = 1.75
option CharacterIntegrityDistanceSlack = 12
option CharacterIntegrityPingAllowance = 1.5
option CharacterIntegrityScoreDecayPerSecond = 2
option CharacterIntegrityCorrectionScore = 12
option CharacterIntegrityKickScore = 40
option CharacterIntegrityMaxConsecutiveBreaches = 8
option CharacterIntegrityCorrectionCooldownSeconds = 1
option CharacterIntegrityReportCooldownSeconds = 1
option CharacterIntegrityHistoryLimit = 32
option EnableRemoteNameRotation = true
option RemoteNameRotationSeconds = 45
option EnableRemoteDecoys = true
option RemoteDecoyCount = 8
```

Fast movement, server teleports, launch forces, custom physics, and streamed character replacement are game-specific. Increase grace or limits for those mechanics instead of treating the defaults as universal. Keep `CharacterIntegrityKick = false` until session evidence shows that your tuned correction and kick thresholds separate normal play from sustained impossible movement.

Avoid unpinned `loadstring(game:HttpGet(...))` loaders in production. If you use an HTTP loader for a private test place, pin it to an immutable commit and replace it with generated ModuleScripts before release.
