# Installation
The recommended way to install Cheeto using [Rokit](https://github.com/rojo-rbx/rokit).
<Steps>

### Installing Cheeto

Open a terminal in your project directory and run the following command:

```sh copy filename="Bash"
rokit add pealz1/cheeto
```

### Updating Cheeto

When a new version of Cheeto releases, using Rokit you can easily update using the following command:

```sh copy filename="Bash"
rokit update pealz1/cheeto
```

</Steps>

## Alternatives

<details>
<summary>GitHub Releases</summary>

You can download pre-built binaries directly from the
[GitHub Releases](https://github.com/pealz1/cheeto/releases) page.

</details>

<details>
<summary>pesde (0.18.5+)</summary>

An official release is available on pesde starting from version 0.18.5.  
To install Cheeto using pesde, open a terminal in your project directory and run the following commands:
```sh copy filename="Bash"
pesde add --dev pealz1/cheeto
pesde install
```

</details>

<details>
<summary>Roblox Studio</summary>
Cheeto offers a companion studio plugin which allows you to write and generate files within Studio without the need for external tooling.  
The studio plugin can be installed from the [Creator Store](https://create.roblox.com/store/asset/77231976488966/Cheeto-Editor).  
Alternatively you can download it from [Github Releases](https://github.com/pealz1/cheeto/releases).
</details>
