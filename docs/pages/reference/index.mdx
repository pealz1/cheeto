## Reading the entries

Every member starts with a signature strip:

<Sig side="server">{"Fire(player: Player, ...data): ()"}</Sig>

The badge says where the member exists. **Server** members are only on the module returned by `ServerOutput`, **Client** members only on `ClientOutput`, and **Server + Client** members on both. **Yields** means the call can suspend the current thread.

Options and fields start with a fact table instead:

<Spec type={<code>number</code>} default={<><code>0</code> (disabled)</>} on="event, function" />

In examples, `Network` is the module you required, for instance `require(ReplicatedStorage.Network.Server)`.
