# map

A `map` is a table whose keys all have one type and whose values all have one type.

```cheeto copy
map Scores = { [string]: u32 }
map Owners = { [u16]: Instance(Player) }
```

## Size

A range after the braces bounds the number of entries. Sending a map outside it raises an error; receiving one drops the event as malformed. The entry count uses only the bytes the maximum needs, so a map of at most 255 entries spends one byte on it.

```cheeto copy
map Scores = {[string(1..20)]: u32}(0..50)
```

Without a range, a map holds at most 65,535 entries, and the runtime drops any received table with more than [`MaxTableKeys`](/reference/options/limits#maxtablekeys) keys (2,048 by default).

## Generics

```cheeto copy
map Dictionary<K, V> = { [K]: V }
map NameToId = Dictionary<string, u32>
```

## Inline maps

A map can also be written inline where a type is expected:

```cheeto copy
event Leaderboard {
    From: Server,
    Type: Reliable,
    Call: ManyAsync,
    Data: map { [string]: u32 }
}
```
