# Options

Options configure the compiler and the generated runtime. They go at the top of the schema, before any declaration, one per line:

```cheeto copy
option ClientOutput = "Network/Client.luau"
option ServerOutput = "Network/Server.luau"
option SecurityProfile = Production
```

An unknown option name is a compile error that lists the valid names. A value of the wrong kind, such as a string where a number is expected, is also a compile error.

## Compile time and runtime

Most options become fields of the generated module's `RuntimeConfig` table. Those can also be changed while the game runs with [`Network.Configure`](/reference/api/module#configure):

```lua copy
Network.Configure({ RateLimitPerSecond = 30, EnableHoneypots = false })
```

A few options only affect what code is generated and cannot be changed at runtime. Each entry states which kind it is.

<Callout type="warning">
Some defaults depend on [`SecurityProfile`](/reference/options/security#securityprofile) and [`SecurityPreset`](/reference/options/security#securitypreset). Entries list the default for each profile where they differ.
</Callout>
