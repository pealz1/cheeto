# CFrame

```cheeto copy
type Pose = CFrame
type CompactPose = CFrame<f16>
```

A `CFrame` is written as its position (three numbers) followed by its orientation as the Euler angles from `CFrame:ToOrientation()` (three numbers). By default all six are `f32`, 24 bytes in total.

## Encoding

`CFrame<T>` uses `T` for all six numbers. `CFrame<A, B>` uses **`B` for the position and `A` for the rotation**:

| Declaration | Position | Rotation |
| --- | --- | --- |
| `CFrame` | `f32` | `f32` |
| `CFrame<f16>` | `f16` | `f16` |
| `CFrame<f32, i16>` | `i16` | `f32` |

<Callout type="error">
The two-parameter form is `CFrame<Position, Rotation>`: `CFrame<i16, f16>` sends a whole-number position and a half-precision rotation. With one parameter, both use it.
</Callout>

The received CFrame is rebuilt with `CFrame.new(position) * CFrame.fromOrientation(x, y, z)`. Positions more than 10⁹ studs from the origin, and non-finite values, are dropped with `Canonicalization`.
